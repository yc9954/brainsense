Reading: the cortex features land in the same league as the 1,408-number vision embedding (on AADB the raw embedding's PCA is a few points ahead; the brain's gain is that every call is interpretable — each call can be traced to named brain areas. AADB ratings are averages over several human raters, which is why the signal is much cleaner than Unsplash popularity. The 360-area version keeps TRIBE's spatial detail that the 9-group pooling throws away — that difference (0.67 → 0.72 here) was the key engineering finding of this project; the shipped aesthetic head uses the 360-area features.
